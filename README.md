# 🚀 ABA利基分析工具 v3.0

## ✨ 功能特点

| 功能 | 说明 |
|------|------|
| 🤖 AI 增强聚类 | 使用大模型进行语义聚类，比词库更精准 |
| 🧠 AI 评论分析 | 深度分析用户评论，生成具体产品改进建议 |
| 📝 AI 报告摘要 | 每个细分市场自动生成可读性强的文字结论 |
| 🔄 无缝回退 | API不可用时自动回退到本地词库 |
| 📊 10维评分 | 市场规模、转化、竞争、成长、利润、品牌垄断、新品存活、卖点接受、价格弹性、季节性 |
| 📋 6 Sheet报告 | 细分市场总览、关键词明细、ASIN排行、评论洞察、入场时机、卖点趋势 |
