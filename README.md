# 🔍 ABA利基分析工具 v5.0

产品开发决策引擎 —— 从数据到产品定义，AI全程介入

## 功能特点

- **双路径选品**：路线一（类目驱动）+ 路线二（数据驱动探索蓝海）
- **AI智能列名映射**：自动识别不同工具导出的列名
- **动态属性识别**：自动提取尺寸、颜色、材质等属性并标准化
- **差评痛点挖掘**：1-3星评论分析 + 提及率计算
- **趋势分析**：季度环比（QoQ）+ 生命周期判断
- **黄金三角报告**：输出价格、人群、卖点的产品定义
